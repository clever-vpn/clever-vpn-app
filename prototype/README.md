# UI 原型（临时）

**这是评估用的可点原型，不是最终代码。** 评估完按结论移植到 `web/`，然后删掉这个目录。

## 怎么打开

双击 `login.html`（或任意一个 `.html`）即可，不需要起服务器、不需要装依赖。
（故意不用 ES module、不发 `fetch`，所以 `file://` 下也能跑。）

## 未登录先看哪一页

`mock.js` 顶部有一行开关：

```js
var LANDING = 'welcome.html';  // 改回 'login.html' 就是"无欢迎页"的变体
```

## 六个状态怎么切换

右上角小浮动条：

| 按钮 | 模拟的状态 |
|---|---|
| 未登录 | 没有会话 → 任何页面都会被弹回 `login.html` |
| 已登录·未订阅 | 能进界面，但点哪都去套餐页 |
| 生效中 | 正常连接 |
| 已过期 | 顶部红条 + 续费入口 |
| 已冻结 | 中性文案 + 客服入口 |
| 设备超限 | 连接时报 `DEVICE_LIMIT` |

另外两个按钮：`明/暗` 切换主题，`换主色` 循环三套品牌色（用来验证"换品牌不塌"）。

## 线路模型（不是「位置」）

界面按**线路**组织，不按地理位置。线路由 **cf-api 的 `GET /api/key-lines`** 下发，
客户端经 **kit 的 `Libbox.getLinesJSON()`** 拿到（字段见 `clever-vpn-android-kit` 的 `Line`）。

**服务端没有「出口型 / 功能型」这种分类**，线路名是租户自己起的，名字本身就是承诺：

| 线路名（租户起） | 用户怎么理解 | 租户怎么实现 |
|---|---|---|
| `香港 01` | 从香港出去 | 一台香港服务器 |
| `TikTok 专用` | 选它就能用 TikTok | 线路挂了**下游代理**，指向外部住宅 IP 服务商的 socks 地址 |
| `ChatGPT` | 选它就能用 ChatGPT | 同上（住宅 IP 才不被风控）|

字段：

| 字段 | 含义 | 给谁看 |
|---|---|---|
| `label` | 线路名 | **用户**（主文本）|
| `icon` + `iconKind` | 国旗国家码 / 功能图标名（`ai` / `streaming` / `gaming` …） | **用户**（左侧图标）—— 图形从 `kit://line-icon/…` 取，见 `BRIDGE.md` §6 |
| `factor` | **流量系数**（计费倍率） | **用户**（`x3`）—— 唯一与用户利益相关的属性 |
| `hasRelay` | 有中继（加速服务） | 排障：设置 →「连接信息」 |
| `hasUpstream` | 有下游代理（外部 socks 出口） | 排障：设置 →「连接信息」 |
| `isDefault` | 缺省线路 | 无选中时用它 |

> **两条纪律**：
> ① 不存在「位置/城市」，线路才是模型；也不要自己发明分类（数据里没有）。
> ② 中继 / 下游代理是**线路的内容属性**，出问题时用来定位；**不在选择线路的地方展示**。
> 用户只看得到名字、图标、流量系数。

## 已经守住的规矩

- 颜色只出现在 `app.css` 的变量区；页面里没有色值
- 品牌值只从 `window.BRAND` 读（`brand.js` 是唯一依赖点）
- 无外部资源：图标是内联 SVG，字体用系统栈，零请求
- 品牌标记只有一份：`brand.js` 里内联的 64×64 单色 SVG（路径取自
  `cf-dashboard/public/img/brand/logo-small-red.svg`，靠 `fill-rule="evenodd"` 镂空出圆环），
  颜色 = `currentColor` ⇒ 亮色跟随主色、暗色转白，不需要第二张图也不需要 `filter`。
  租户给了 `BRAND.icon` 才换成 `<img>`（那时才用 `filter` 把深名单色图转白）
- 未登录只能看 `login.html`；未订阅点哪都到 `plans.html`（白名单：底部导航、线路列表、设置、退出登录）
- 每屏一个实心按钮
- **支付只认三个词**（契约 v20 §2.4.0）：`payment_method`（唯一用户可见）、
  网关/驱动/渠道码（内部，永不下发）、商店轨道（**编译期属性**，不是请求参数）。
  `/plans` 保持无状态：同一份响应，客户端按自己的构建取 `payment_methods` 或
  `store_product_id` 其中之一；置灰时按钮一律写「不可购买」+ 整句原因
- **根页面没有返回**：`index / lines / plans / account` 是四个 tab 根页面，顶栏左侧不放返回；
  只有推入页（`settings → split → region`、`account → redeem`）才有，且回到上一层。
  唯一例外：匿名访问 `plans.html` 时没有底部 tab，那一页临时降级为推入页，给返回（去欢迎页）
- **状态与数字共用一条中轴**：大圆钮、状态词、计时、上下行、线路胶囊的中心都在屏幕正中。
  计时不塞进状态同一行（那样"已连接"这个词会被顶偏，对称感就没了），而是另起一行、小一号、
  次要色 —— 从属信息换行，锚点不动
- **间距按视觉算，不按盒子算**：`已连接 / 计时` → `流量` → `线路` 三段之间要"看着"等距。
  文字行自带上下各半的行距留白，数字下面还有一段降部空白，所以 `.stats` 上用了
  `line-height: 1` + `margin-top: -4px`（盒间距 12/16，视觉间距 16.5/16.5）。
  那个负边距是补偿，不是笔误 —— 删掉它流量行看起来就不居中了
- **动 = 还没完成，静 = 完成了**：大圆钮只有"连接中"才持续动（0.95s 缺口弧 + 心跳）；
  **已连接完全静止**，只在刚连上的一瞬放一圈确认波（0.9s）。动效只用 `transform`/`opacity`，
  不跑 JS 定时器，`prefers-reduced-motion: reduce` 时全部关掉
- **`›` 只表示"点进去还有内容"**：会打开新层级的行才留 `›`；切换类（选线路、开关）
  不留箭头，用勾选标记 + `role="radio"` / `aria-checked`
- **已连接时切换线路要确认**：线路是连接的参数，bridge@1 没有原子"换线"，
  切换 = 断开 + 重连。三种状态三套做法：
  **未连接**随手切（不弹窗）；**连接中**忽略点击（别打断半截状态，说明写「连接中…」）；
  **已连接**弹确认「切换到 X / 当前连接会断开。」→ 取消 / 切换，确认后先断开再切。
  线路页顶栏还有「断开」直通（连接中它同时是"取消"）
- **选中态要有颜色，不只是一个勾**：选中行 `color-mix(brand 11%)` 底色 + 主色勾 + 字重 500，
  扫视列表时不用逐行找那个小勾
